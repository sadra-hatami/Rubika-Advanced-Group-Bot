# 📖 درباره

**Rubika Advanced Group Bot** الان پرچمدار ربات‌های گروه این پروفایل است.

مالک ربات را به گروه اضافه می‌کند، دسترسی ادمین می‌دهد و سیستم‌ها را برای همان گروه روشن می‌کند. تنظیمات، سطح، اخطار، دستور سفارشی و لاگ در SQLite می‌مانند.

کد جدید گروه در همین مخزن است. پلتفرم کامل قبلی به [Rubika Group Bot](https://github.com/sadra-hatami/Rubika-Group-Bot) منتقل شده.

> **جمله کوتاه:** *پلتفرم گروه روبیکا با نظارت، اتوماسیون، سطح‌بندی و ابزار سرگرمی.*

# ▶️ اجرا

```bash
git clone https://github.com/sadra-hatami/Rubika-Advanced-Group-Bot.git
cd Rubika-Advanced-Group-Bot
pip install rubka aiohttp httpx requests beautifulsoup4 jdatetime
python index.py
```

ربات را به گروه اضافه کن، ادمین بده، بعد سیستم‌ها را روشن کن.
